## Launch

Every driver package starts the same way; per-repo configuration (environment id, model path, port, baud rate, VISA resource) lives in the package's `driver.py`, never in launch flags:

```
mhs serve <driver-dir>
```

A package is done when `python3 -m mhs.driver check <driver-dir> --backend fake` exits 0 (evidence `contract_checked`; a fake never yields an MHS-Device level).

## Capability mapping

| native call | OpenMHS target | notes |
|---|---|---|
| serial port settings (port, baud, parity) | lifecycle: transport configuration in driver.py | never launch flags; a fake or a transcript replaces the port |
| query command (for example `IN_PV_00`) | reads: the measure class that fits, else cap.sensing.read.v1 | parse the reply; the unit comes from the manual |
| set command (for example `OUT_SP_00 25.0`) | writes: cap.device.configure.v1, or a write class that fits | every limit cites its source |
| a raw write(command) | only as a named command-map entry | never cap.actuation.gpio.v1 for an arbitrary command |
| stop or output-off command | safety_bindings: e-stop and safe state | written under the short write lock; it aborts a pending reply wait |

Class ids come from `python3 -m mhs.driver catalog search <words>`. The deprecated classes cap.device.describe.v1, cap.world.state.v1, cap.world.snapshot.v1 and cap.world.restore.v1 are replaced by the protocol methods mhs.devices.get, mhs.resource.read, mhs.snapshot and mhs.restore.

## Safety

The risk floor of a device is the highest catalogue `risk_class` of its classes (CAP-017); a driver may declare a higher risk, never a lower one. Hardware at R1 or above needs an `@estop` and a non-empty safe state. A serial line can drive pumps, heaters and motors. Port names and baud rates are deployment-specific and are never guessed at run time.

## Fidelity

A transcript fake proves the framing and the command map, not the physics.

## Pitfalls

Line endings and checksums vary; unbounded reads hang; USB re-enumeration renames ports; error replies are vendor-specific.
