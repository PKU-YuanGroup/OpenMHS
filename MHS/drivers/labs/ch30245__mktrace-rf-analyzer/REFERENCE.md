## Safety

- E-stop: software, latching, native stop `abort_active_session`.
- Safe state: unconfirmed: closing the active TCP session does not confirm stopped analyzer sweeps or RF output; the endpoint latch refuses new commands and the e-stop reports SAFE_STATE_UNREACHED (achieved by nothing declared).
- OpenMHS is not a safety certification and not a safety-rated channel; the physical e-stop stays authoritative.

## Facts

- NaClient is the analyzer client class; its constructor stores host and port and defaults the port to 5025 (upstream_code: pna.py:236-241)
- A session is a raw TCP socket to host:port with a 10 s connect timeout and a default 180 s I/O timeout (upstream_code: pna.py:178-182)
- Every SCPI command is sent as ASCII terminated by a newline (upstream_code: pna.py:203-204)
- identify opens a short-lived session, queries *IDN? and closes the session (upstream_code: pna.py:254-264)
- The supported identity gate accepts Keysight PNA/N522/N523/N524/N526/N529 and Rohde & Schwarz ZVA/ZVB/ZVT identities only (upstream_code: pna.py:167-175)
- capture accepts only 1, 2 or 4 ports and rejects every other port count before opening a session (upstream_code: pna.py:274-279)
- capture reads *IDN? and dispatches to the Keysight or the Rohde & Schwarz capture sequence (upstream_code: pna.py:280-299)
- The Keysight capture selects the measurement, starts a single sweep, saves a Touchstone file and transfers it back with MMEM:TRAN? (upstream_code: pna.py:696-716)
- The Rohde & Schwarz capture turns continuous sweep off, starts an immediate sweep and saves/transfers a Touchstone file (upstream_code: pna.py:831-844)
- configure_measurements adds missing Keysight S-parameter measurements without replacing existing ones (upstream_code: pna.py:304-333)
- configure_measurements refuses non-Keysight analyzers without changing analyzer state (upstream_code: pna.py:320-324)
- abort_active_session closes the active I/O session; it sends no SCPI abort command (upstream_code: pna.py:247-252)
- The upstream validates a received Touchstone payload before atomically replacing the target file (upstream_code: pna.py:343-363)
- The default capture file name is a timestamped MKTrace name with the .s1p, .s2p or .s4p suffix (upstream_code: pna.py:125-128)
- The README says the MKCal calibration workflow is simulator-only (vendor_doc: README.md:5-7)
- The README says the automated tests do not contact real hardware (vendor_doc: README.md:67-69)
