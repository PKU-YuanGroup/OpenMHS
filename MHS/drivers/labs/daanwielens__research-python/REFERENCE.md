## Safety

- E-stop: software, latching, native stop `RANGE 0`.
- Safe state: heater range set to 0 (off), so the heater output is disabled (achieved by `x-cap.daanwielens.heater_off.v1`).
- OpenMHS is not a safety certification and not a safety-rated channel; the physical e-stop stays authoritative.
