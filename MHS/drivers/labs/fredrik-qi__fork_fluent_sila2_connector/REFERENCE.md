## Safety

- E-stop: software, latching, native stop `stop_method`.
- Safe state: After StopMethod returned, the connector's State reads RunModeRunFinished (documented as finished or aborted) or EditMode within 0.4 s, else SAFE_STATE_UNREACHED with the latch held; State caches FluentControl mode-change events (not a fresh query), StopMethod's effect on an API command in flight is not in the clone, and FluentControl and the instrument stay powered with tips, liquid and labware where the stop left them. (achieved by `x-cap.fredrik-qi.stop_method.v1`).
- Operator-required limits not yet set: `aspirate.volume`, `aspirate.well_offset`, `dispense.volume`, `dispense.well_offset`, `set_location.rotation`, `set_location.target_site`, `transfer_labware.target_position`. Hardware use is refused (MHS.SAFETY.LIMITS_UNSET) until site-limits.json supplies them.
- OpenMHS is not a safety certification and not a safety-rated channel; the physical e-stop stays authoritative.
