## Safety

- E-stop: software, latching, native stop `stop`.
- Safe state: heater outputs 1 and 2 commanded off: the e-stop sends RANGE n,0 and OUTMODE n,0,0,0 without a readback, and the safe-state action sends the same and fails unless RANGE? and OUTMODE? read off for both outputs; stored setpoints and ramps stay, nothing is cooled and no previous configuration is restored, so the sample can keep changing temperature; the class addresses heater outputs 1 and 2 only (achieved by `x-cap.msuarezrodriguez.heaters_off.v1`).
- Operator-required limits not yet set: `setpoint`, `ramp_rate`. Hardware use is refused (MHS.SAFETY.LIMITS_UNSET) until site-limits.json supplies them.
- OpenMHS is not a safety certification and not a safety-rated channel; the physical e-stop stays authoritative.

## Facts

- LakeShore336 is a minimal QCoDeS driver for the Lake Shore Model 336 temperature controller (upstream_code: instruments/lakeshore_336.py:10-12)
- The class reads inputs A-D, gets and sets loops 1-4, gets and sets heater ranges on outputs 1-2, configures OUTMODE and RAMP, and offers manual heater output MOUT (upstream_code: instruments/lakeshore_336.py:14-20)
- The class does not send *RST on init, to preserve sensor curves and setup; it sends only *CLS (upstream_code: instruments/lakeshore_336.py:22-26)
