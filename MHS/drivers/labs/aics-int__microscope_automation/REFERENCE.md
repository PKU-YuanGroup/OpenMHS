## Safety

- E-stop: software, latching, native stop `stop`.
- Safe state: live acquisition stopped (ZEN live mode off); this package starts no stage, focus or pump movement (achieved by `x-cap.aics-int.live_mode_stop.v1`).
- OpenMHS is not a safety certification and not a safety-rated channel; the physical e-stop stays authoritative.
