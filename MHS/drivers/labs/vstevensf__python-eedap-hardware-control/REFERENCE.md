## Safety

- E-stop: software, latching, native stop `close`.
- Terminal e-stop: Upstream: PriorStage.close() only closes the serial port and sends no stop command (proscan.py:180-186), and only constructing a new PriorStage opens a port (proscan.py:147-150, 25-36). Package policy: this driver never reopens the port inside an endpoint, so a new endpoint, which repeats the connection handshake (proscan.py:40-56), is the only recovery. A move already sent is not stopped; the clone has no stop, abort or position query. Every reset after an e-stop on the same endpoint is refused (`terminal_estop`).
- Safe state: serial connection closed; this driver can send no further command, but a move already sent may continue because the clone has no stop command (achieved by nothing declared).
- Operator-required limits not yet set: `move_xy.x`, `move_xy.y`. Hardware use is refused (MHS.SAFETY.LIMITS_UNSET) until site-limits.json supplies them.
- OpenMHS is not a safety certification and not a safety-rated channel; the physical e-stop stays authoritative.
