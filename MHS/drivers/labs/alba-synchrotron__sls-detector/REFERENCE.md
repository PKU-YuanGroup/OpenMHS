## Safety

- E-stop: software, latching, native stop `stop`.
- Safe state: acquisition stop requested with the native stop_acquisition command (STOP_ACQUISITION on the stop port, acknowledged by the detector's reply; a FAIL reply raises); the run status read after the command is reported, not an independently sensed quiescence (achieved by `x-cap.alba-synchrotron.stop_acquisition.v1`).
- Operator-required limits not yet set: `energy_threshold`, `exposure_time`, `nb_frames`, `nb_cycles`, `frame_period`, `delay_after_trigger`. Hardware use is refused (MHS.SAFETY.LIMITS_UNSET) until site-limits.json supplies them.
- OpenMHS is not a safety certification and not a safety-rated channel; the physical e-stop stays authoritative.
