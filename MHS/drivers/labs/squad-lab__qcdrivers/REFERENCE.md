## Safety

- E-stop: software, latching, native stop `*RST`, latency 5000 ms.
- Safe state: every crosspoint open in the firmware's route buffers and shifted out to the chips: *RST clears both buffers, flushes them and prints 'Reset complete' (firmware.ino:51-56); the e-stop succeeds only when the next two lines, after every line still owed by an earlier command, are 'Clear complete' then 'Reset complete'; the analog switches are not sensed (achieved by nothing declared).
- Operator-required limits not yet set: `connect.x`, `connect.y`, `status.x`, `status.y`. Hardware use is refused (MHS.SAFETY.LIMITS_UNSET) until site-limits.json supplies them.
- OpenMHS is not a safety certification and not a safety-rated channel; the physical e-stop stays authoritative.

## Facts

- Muxi is a QCoDeS VisaInstrument that controls an AD75019 crosspoint switch over pyVISA (upstream_code: src/qcdrivers/squad/mux/mux.py:29-35)
- The constructor sets the baud rate (default 9600), newline write and CRLF read terminators and a 2000 ms VISA timeout, calls connect_message and clears the VISA handle (upstream_code: src/qcdrivers/squad/mux/mux.py:37-58)
- send_command queries the VISA handle; on VisaIOError it calls self.visa.handle.clear(), an attribute path the class never defines, before sleeping 0.1 s and querying again (upstream_code: src/qcdrivers/squad/mux/mux.py:85-92)
- switch32 returns 'Route skipped: disabled range' without sending a command for x or y in 12-15 or 28-31, and otherwise sends SWITCH32 x,y (upstream_code: src/qcdrivers/squad/mux/mux.py:105-114)
- status sends MUX:STATUS? PIN,OUT, a command the firmware does not register (upstream_code: src/qcdrivers/squad/mux/mux.py:144-146)
- reset sends *RST through send_command, which reads one reply line (upstream_code: src/qcdrivers/squad/mux/mux.py:148-158)
- printconfig sends PRINT and then reads a further line from the VISA handle (upstream_code: src/qcdrivers/squad/mux/mux.py:170-172)
- close closes the VISA handle (upstream_code: src/qcdrivers/squad/mux/mux.py:225-235)
- The firmware registers the commands *IDN?, *RST, STAT?, SWITCH16, SWITCH32, CLEAR and PRINT (upstream_code: src/qcdrivers/squad/mux/helpers/firmware.ino:34-40)
- *IDN? prints the line 'SQUAD, Arduino AD75019 Switch, 1.0, 1.0' (upstream_code: src/qcdrivers/squad/mux/helpers/firmware.ino:47-49)
- The *RST handler runs Clear, flushes the 16x16 and the 32x32 matrices and then prints 'Reset complete' (upstream_code: src/qcdrivers/squad/mux/helpers/firmware.ino:51-56)
- Clear sets both route buffers to zero and prints 'Clear complete' (upstream_code: src/qcdrivers/squad/mux/helpers/firmware.ino:108-112)
- SWITCH32 prints 'Route skipped: disabled range' for x or y in 12-15 or 28-31; otherwise it adds the route, flushes the 32x32 matrix and prints 'Route added 32x32' (upstream_code: src/qcdrivers/squad/mux/helpers/firmware.ino:71-88)
- STAT? x,y prints '16x16: ' and '32x32: ' each followed by 1 or 0 from isRouted of the two route buffers, or 'Usage: STAT? x,y' without two parameters (upstream_code: src/qcdrivers/squad/mux/helpers/firmware.ino:90-106)
- The two matrix objects share one PCLK, SCLK and SIN pin set (upstream_code: src/qcdrivers/squad/mux/helpers/firmware.ino:6-13)
- AD75019_24.flush shifts the route buffer out bit by bit and then pulses PCLK; clear sets every word of the buffer to 0 (upstream_code: src/qcdrivers/squad/mux/helpers/AD75019_24.cpp:95-150)
- isRouted reads the bit of the configuration buffer, not the chip (upstream_code: src/qcdrivers/squad/mux/helpers/AD75019_24.cpp:91-93)
- The 32x32 matrix class's X and Y pin mappings have 32 entries (upstream_code: src/qcdrivers/squad/mux/helpers/AD75019_24.h:115-116)
- The 16x16 matrix class's X and Y pin mappings have 16 entries (upstream_code: src/qcdrivers/squad/mux/helpers/AD75019.h:124-125)
- The 16x16 matrix class's isRouted indexes its X and Y pin mappings with the x and y it is given (upstream_code: src/qcdrivers/squad/mux/helpers/AD75019.cpp:79-82)
- STAT? passes the x and y it parses to isRouted of both the 16x16 and the 32x32 matrix (upstream_code: src/qcdrivers/squad/mux/helpers/firmware.ino:90-96)
- Four AD75019 chips are daisy-chained for the 24x24 array, each with X12-X15 and Y12-Y15 disabled and grounded (vendor_doc: src/qcdrivers/squad/mux/README.md:8-9)
