## Safety

- E-stop: software, latching, native stop `set_lamp`.
- Safe state: lamp command off (0x03 0x00) and sample-arm magnet command off (0x0F 0x00), the commands the upstream close() sends; both are unacknowledged USB writes, the clone states nothing about the arm position after the magnet is released, and a USB read already in flight is not interrupted (achieved by nothing declared).
- Operator-required limits not yet set: `measure_spectrum.wavelength_max`, `measure_spectrum.wavelength_min`. Hardware use is refused (MHS.SAFETY.LIMITS_UNSET) until site-limits.json supplies them.
- OpenMHS is not a safety certification and not a safety-rated channel; the physical e-stop stays authoritative.

## Facts

- NanoDrop1000 is a USB device with VID 0x2457, PID 0x1002, a command endpoint, a spectrum endpoint and a text/status endpoint (upstream_code: Code/nanodrop.py:7-12)
- connect() finds the device by VID/PID, sets its configuration, clears the three endpoint halts, sends the wake command 0x08 and the init command 0x01, then downloads the factory coefficients and calculates the wavelength axis (upstream_code: Code/nanodrop.py:23-44)
- close() turns the lamp and magnet off, resets the USB device and disposes the USB resources (upstream_code: Code/nanodrop.py:46-56)
- set_lamp(state) writes command 0x03 with 0xFF for on and 0x00 for off (upstream_code: Code/nanodrop.py:62-64)
- set_magnet(state) writes command 0x0F with 0xFF for on and 0x00 for off (upstream_code: Code/nanodrop.py:66-68)
- take_blank sets the magnet True before its dark reading, with the comment 'Arm down' (upstream_code: Code/nanodrop.py:139-143)
- measure_absorbance sets the magnet True before its sample reading (upstream_code: Code/nanodrop.py:160-162)
- set_integration_time(ms) documents the valid range 3 to 65535 ms, clamps outside it and writes command 0x02 with a 16-bit little-endian exposure (upstream_code: Code/nanodrop.py:70-81)
- _calculate_x_axis builds a 2048-element wavelength array in nanometres from factory coefficients 1 through 4 (upstream_code: Code/nanodrop.py:103-108)
- get_raw_spectrum() flushes stale image data, writes command 0x09 and decodes 64 reads of 64 bytes into 2048 16-bit pixels (upstream_code: Code/nanodrop.py:111-131)
- take_blank(integration_ms=20) acquires a dark frame with the lamp off, then a blank frame with the lamp on, and turns the lamp and magnet off afterwards (upstream_code: Code/nanodrop.py:134-153)
- measure_absorbance(integration_ms=20) requires a stored dark and blank spectrum, arms the magnet, turns the lamp on, reads one frame and returns the wavelength axis with -log10((sample-dark)/(blank-dark)) (upstream_code: Code/nanodrop.py:155-179)
- The example script plots the active sensor area roughly from 220 nm to 750 nm (upstream_code: Code/main.py:22-28)
- The installation guide says the NanoDrop uses an older USB 1.1 microcontroller and that its Python driver is installed with Zadig's libusb-win32 replacement (vendor_doc: Code/NanoDropInstalInstructions.txt:3-20)
- The PyLabRobot wrapper class ThermoFisherNanoDrop1000 constructs one ThermoFisherNanoDrop1000Driver and one absorbance backend sharing it (upstream_code: Code/ThermoFisherNanoDrop1000_PLR_V1.py:220-235)
