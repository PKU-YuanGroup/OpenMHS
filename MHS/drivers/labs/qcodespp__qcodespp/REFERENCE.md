## Safety

- E-stop: software, latching, native stop `stop`.
- Safe state: source output off with :OUTP:STAT 0 (the command of the upstream output Parameter); the configured source level remains set but is not driven, and the e-stop latch refuses further actuation (achieved by `x-cap.qcodespp.output_off.v1`).
