## Safety

- E-stop: software, latching, native stop `stop_from_status`.
- Safe state: the status-page Stop command is sent (POST bounded to two seconds) and the stop holds only when a fresh status read then reports Idle or Stopped, the states the upstream's stop_and_save waits for; that wait may last up to 15 s upstream, so an attempt can be reported unreached and is retried; any other state, a timeout or an error is a failed safe state; lid, lasers and queued firmware work are not confirmed (achieved by `x-cap.vcjdeboer.odyssey_safe_stop.v1`).
- Operator-required limits not yet set: `width_cm`, `height_cm`, `capture.exposure_ms`, `capture.height`, `capture.width`. Hardware use is refused (MHS.SAFETY.LIMITS_UNSET) until site-limits.json supplies them.
- OpenMHS is not a safety certification and not a safety-rated channel; the physical e-stop stays authoritative.

## Facts

- The Odyssey Classic is a LI-COR model 9120 infrared imaging system operated by a FastAPI control app over the instrument's embedded HTTP CGI interface (vendor_doc: README.md:3-9)
- The upstream transport is an aiohttp client with Basic Auth for an Apache/mod_perl CGI interface reverse-engineered from the browser (upstream_code: plr_v4/odyssey/connection.py:3-8)
- The scan setup form posts to /scanapp/scan/nonjava/configure.pl and scan commands go to command.pl?action=start\|stop\|pause\|cancel (upstream_code: plr_v4/odyssey/connection.py:10-16)
- configure.pl returns a 302 redirect to the initializing.pl countdown, and configure_scan follows the redirect to start hardware initialization (upstream_code: plr_v4/odyssey/connection.py:360-408)
- The full seven-step initializing.pl countdown must be polled before start because skipping it skips motor and laser warm-up (upstream_code: plr_v4/odyssey/connection.py:455-464)
- start_scan, stop_scan, pause_scan and cancel_scan send command.pl actions start, stop, pause and cancel; an error page or 'not configured' is raised (upstream_code: plr_v4/odyssey/connection.py:487-525)
- The status page returns the scanner state, current user, percent complete, time remaining and lid status (upstream_code: plr_v4/odyssey/connection.py:544-566)
- The status parser extracts the lid status from the status page (upstream_code: plr_v4/odyssey/connection.py:780-786)
- The device card declares a lid interlock (upstream_code: plr_v4/odyssey/device_card.py:47-49)
- stop_from_status posts action=Stop to the status page, is the documented way to release a paused or stuck scanner without the scan console, and returns the response text without checking it (upstream_code: plr_v4/odyssey/connection.py:568-578)
- After command.pl stop, stop_and_save polls the status page until the state reads idle or stopped and raises when that takes longer than _STOP_IDLE_TIMEOUT_SEC (upstream_code: plr_v4/odyssey/scan_backend.py:103-117)
- _STOP_IDLE_TIMEOUT_SEC is 15.0 (upstream_code: plr_v4/odyssey/scan_backend.py:38)
- OdysseyDriver.stop closes the HTTP session; it is not a scanner stop (upstream_code: plr_v4/odyssey/connection.py:347-351)
- get_jpeg_preview fetches a JPEG preview the instrument renders server-side with the requested contrast, channels and background (upstream_code: plr_v4/odyssey/connection.py:659-687)
- download_tiff downloads one raw TIFF channel (700 or 800) from /scan/image/<name>-<channel>.tif (upstream_code: plr_v4/odyssey/connection.py:601-618)
- get_scan_progress reads the imaging info panel and returns dimensions, file size and time left (upstream_code: plr_v4/odyssey/connection.py:580-597)
- get_instrument_info fetches the instrument information page (serial number, software version) (upstream_code: plr_v4/odyssey/connection.py:723-728)
- The device card records 700 nm and 800 nm solid-state diode lasers with 80 mW peak power each (upstream_code: plr_v4/odyssey/device_card.py:26-40)
- The device card records scan resolutions 21, 42, 84, 169 and 337 um, quality levels lowest through highest, an intensity range of 0.5 to 10.0 in 0.5 steps, a 25 x 25 cm scan area and a focus offset range of 0.0 to 4.0 mm (upstream_code: plr_v4/odyssey/device_card.py:16-24)
- The canonical instrument states are Idle, Configured, Initializing, Scanning, Paused, Stopped, Completed and Failed, and unrecognized status text is mapped to Idle (upstream_code: plr_v4/odyssey/status_backend.py:27-67)
- The upstream ships in-memory simulated scan, image and status backends (upstream_code: plr_v4/odyssey/simulated.py:1-10)
- Credentials are read from ODYSSEY_USER and ODYSSEY_PASS (upstream_code: plr_v4/odyssey/connection.py:82-83)
- When host is None, from_env reads ODYSSEY_HOST (upstream_code: plr_v4/odyssey/connection.py:281-298)
