## Safety

- E-stop: software, latching, native stop `stop`.
- Safe state: trigger generation stopped by the native PQSC stop(deep=True), documented to synchronize the device and the data server after the disable (the implementation is zhinst-toolkit's, outside the clone); the device settings and the connected instruments are not reset, so their configuration and any sequence they run on their own are left as they were (achieved by nothing declared).
- Operator-required limits not yet set: `wait_done.timeout`. Hardware use is refused (MHS.SAFETY.LIMITS_UNSET) until site-limits.json supplies them.
- OpenMHS is not a safety certification and not a safety-rated channel; the physical e-stop stays authoritative.

## Facts

- PQSC is the QCoDeS driver class for the Zurich Instruments PQSC (upstream_code: src/zhinst/qcodes/driver/devices/pqsc.py:10-11)
- run() starts sending out triggers and activates trigger generation over the ZSync ports (upstream_code: src/zhinst/qcodes/driver/devices/pqsc.py:18-30)
- arm() configures the execution engine and clears the register bank; repetitions and holdoff optionally set the number of triggers and the time between repeated triggers, and the hold-off has a minimum value and a granularity of 100 ns (upstream_code: src/zhinst/qcodes/driver/devices/pqsc.py:149-181)
- arm_and_run() combines arm and run and synchronizes between the device and the data server after arming and running (upstream_code: src/zhinst/qcodes/driver/devices/pqsc.py:32-50)
- stop() is documented to stop the trigger generation; deep (default True) performs a synchronization between the device and the data server after the disable, and the call forwards to the toolkit object (upstream_code: src/zhinst/qcodes/driver/devices/pqsc.py:52-61)
- A deep operation on a node blocks until the device has acknowledged it and returns the acknowledged value (upstream_code: src/zhinst/qcodes/qcodes_adaptions.py:279-282)
- zhinst-qcodes requires zhinst-toolkit>=1.4.0 and qcodes>=0.35.0 (upstream_code: pyproject.toml:22-27)
- wait_done() waits until trigger generation and feedback processing is done, bounded by timeout in seconds, and raises TimeoutError when the sequence is not done before it (upstream_code: src/zhinst/qcodes/driver/devices/pqsc.py:63-76)
- check_ref_clock() checks whether the reference clock is locked successfully, bounded by timeout in seconds (upstream_code: src/zhinst/qcodes/driver/devices/pqsc.py:78-93)
- get_idn() returns the vendor, model, serial and firmware of the connected device (upstream_code: src/zhinst/qcodes/driver/devices/base.py:48-55)
- factory_reset() loads the factory default settings (upstream_code: src/zhinst/qcodes/driver/devices/base.py:60-68)
- get_streamingnodes() returns the streaming nodes available on the device (upstream_code: src/zhinst/qcodes/driver/devices/base.py:88-90)
- set_transaction() returns the toolkit transaction context manager that bundles node set commands; it is not a value setter (upstream_code: src/zhinst/qcodes/driver/devices/base.py:92-112)
- serial and device_type are properties of the instrument (upstream_code: src/zhinst/qcodes/driver/devices/base.py:114-122)
- the device-creator PQSC constructor creates a ZISession for host and port and connects the serial with connect_device(serial, interface=interface) (upstream_code: src/zhinst/qcodes/device_creator.py:255-276)
