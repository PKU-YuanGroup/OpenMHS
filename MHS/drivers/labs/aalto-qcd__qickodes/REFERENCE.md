## Safety

- E-stop: software, latching, native stop `stop`.
- Safe state: No safe state is certified: the e-stop clears the instrument's macro list, so no new run of this object can start, and reports SAFE_STATE_UNREACHED with the latch held; a program already running on the board and an armed DDR4 buffer continue, because the pinned upstream has no stop, abort or disarm method (achieved by nothing declared).
- OpenMHS is not a safety certification and not a safety-rated channel; the physical e-stop stays authoritative.
