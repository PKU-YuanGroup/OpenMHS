## Actions

### `plan_pick_and_place`

`x-cap.unity-technologies.pick_place_plan.v1` on `main`: invoke, risk R1, extension.

Plan (never execute) the five UR3 pick-and-place trajectories; executed is false. A command: it changes the node's shared planner, so never call while Unity plans; a zero quaternion is refused.

Inputs:

| Field | Type | Unit | Required | Limit | Description |
|---|---|---|---|---|---|
| `start_joints_deg` | array | deg | yes | operator required (not set) | Start angles of the six arm joints, in planner order |
| `pick_position` | array | m | yes | operator required (not set) | Pick x, y, z in the planning frame |
| `pick_orientation` | array | 1 | yes | operator required (not set) | Pick quaternion x, y, z, w |
| `place_position` | array | m | yes | operator required (not set) | Place x, y, z in the planning frame |
| `place_orientation` | array | 1 | yes | operator required (not set) | Place quaternion x, y, z, w |

Outputs:

| Field | Type | Unit | Description |
|---|---|---|---|
| `joint_names` | array |  | Each plan's joint names, in plan order (pre grasp, grasp, pick up, place, post place) |
| `points` | array |  | Each plan's trajectory points, in plan order; a plan starts where the previous ends |
| `executed` | boolean |  | Always false: the package plans only and executes nothing |

## Safety

- E-stop: software, latching, no native stop (software latch only).
- Safe state: Plan-only package: it sends nothing that executes a plan or commands the Unity arm, its gripper or any controller. An e-stop latches this endpoint in software and refuses further planning requests; a planning request already sent is not awaited. It does not reach a pick-and-place that Unity started from its own Pose Estimation button: that runs in Unity's coroutine and stops only in the Unity editor. (achieved by nothing declared).
- Operator-required limits not yet set: `plan_pick_and_place.pick_orientation`, `plan_pick_and_place.pick_position`, `plan_pick_and_place.place_orientation`, `plan_pick_and_place.place_position`, `plan_pick_and_place.start_joints_deg`. - OpenMHS is not a safety certification and not a safety-rated channel; the physical e-stop stays authoritative.
