## Safety

- E-stop: software, latching, no native stop (software latch only).
- Safe state: Plan-only package: it sends nothing that executes a plan or commands the Unity arm, its gripper, or the Niryo action server. An e-stop latches this endpoint in software and refuses further planning requests. A request already sent is not awaited. There is no unpause. A pick-and-place that Unity started from its own button runs in Unity's coroutine and is not reached. (achieved by nothing declared).
