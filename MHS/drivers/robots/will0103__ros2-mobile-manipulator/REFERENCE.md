## Actions

### `move_robot`

`x-cap.will0103.move-robot.v1` on `main`: invoke, risk R2, extension, cancellable.

Send one MoveRobot velocity/duration goal to the ROS 2 /move_robot action server.

Inputs:

| Field | Type | Unit | Required | Limit | Description |
|---|---|---|---|---|---|
| `linear_vel_x` | number | m/s | yes | operator required (not set) | Commanded forward velocity, mapped to the MoveRobot linear_vel_x goal field |
| `angular_vel_z` | number | rad/s | yes | operator required (not set) | Commanded turn rate, mapped to the MoveRobot angular_vel_z goal field |
| `duration` | number | s | yes | operator required (not set) | Goal duration, mapped to the MoveRobot duration goal field |

Outputs:

| Field | Type | Unit | Description |
|---|---|---|---|
| `success` | boolean |  | Upstream result success flag; true only when the execute loop completes normally |
| `message` | string |  | Upstream terminal result message; the cancel path sets success false |
| `sent_linear_vel_x` | number | m/s | The linear_vel_x handed to rosbridge (the transmitted request, not a measurement) |
| `sent_angular_vel_z` | number | rad/s | The angular_vel_z handed to rosbridge (the transmitted request, not a measurement) |
| `sent_duration` | number | s | The duration handed to rosbridge (the transmitted request, not a measurement) |

## Safety

- E-stop: software, latching, native stop `/world/empty/control`, latency 1500 ms.
- Safe state: The world empty is paused: after the WorldControl pause two fresh stats samples, 40 ms or more apart within 600 ms, reported paused true, so the world does not step and the differential drive applies no stored twist; it is the paused flag in that window, not a measured standstill, it needs the operator-run ros_gz bridges, and no unpause is offered: the stored twist, the arm joint targets and a still-running move_robot queue act when the operator resumes the world. (achieved by nothing declared).
- Operator-required limits not yet set: `move_robot.angular_vel_z`, `move_robot.duration`, `move_robot.linear_vel_x`. Hardware use is refused (MHS.SAFETY.LIMITS_UNSET) until site-limits.json supplies them.
- OpenMHS is not a safety certification and not a safety-rated channel; the physical e-stop stays authoritative.
