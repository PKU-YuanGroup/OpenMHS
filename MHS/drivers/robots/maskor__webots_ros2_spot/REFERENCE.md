## Safety

- E-stop: software, latching, native stop `/Spot/float_mode`, latency 7000 ms.
- Sensed-confirmation stop (simulated devices only; SAFE-049): the request steps `/Spot/float_mode` (service), `/Spot/lie_down` (service) prove nothing by themselves. The e-stop is achieved only when every source (`/Spot/odometry` (nav_msgs/msg/Odometry, stamp `header.stamp`)) delivers 3 fresh samples, on subscriptions opened after the request, that satisfy every term below within 3000 ms of the first transmission; otherwise it fails `MHS.SAFETY.SAFE_STATE_UNREACHED`, the latch is kept and the background retry sends the request again. A reset re-confirms without a request.
- Sensed state: After /Spot/float_mode is set false and /Spot/lie_down is requested, three consecutive fresh /Spot/odometry samples show the base still in x, y and orientation and inside the lying height band; the service answers are not the stop..
- Predicate: `max - min of odom.pose.pose.position.x over the window <= rest_x`.
- Predicate: `max - min of odom.pose.pose.position.y over the window <= rest_y`.
- Predicate: `odom.pose.pose.position.z >= lying_z.min and <= lying_z.max`.
- Predicate: `max - min of odom.pose.pose.orientation.x over the window <= still_qx`.
- Predicate: `max - min of odom.pose.pose.orientation.y over the window <= still_qy`.
- Predicate: `max - min of odom.pose.pose.orientation.z over the window <= still_qz`.
- Predicate: `max - min of odom.pose.pose.orientation.w over the window <= still_qw`.
- Threshold `rest_x` (max): operator_required (the clone states no at-rest bound on pose.pose.position; the operator supplies the largest change over the confirmation window that still counts as still).
- Threshold `rest_y` (max): operator_required (the clone states no at-rest bound on pose.pose.position; the operator supplies the largest change over the confirmation window that still counts as still).
- Threshold `lying_z.min` (min): operator_required (the clone states no lying height band for pose.pose.position.z; the operator supplies the band a lying base must stay inside).
- Threshold `lying_z.max` (max): operator_required (the clone states no lying height band for pose.pose.position.z; the operator supplies the band a lying base must stay inside).
- Threshold `still_qx` (max): operator_required (the clone states no at-rest bound on pose.pose.orientation; the operator supplies the largest change of this quaternion component over the confirmation window that still counts as still. Twist is not the check: the second publish in one step can carry a zero finite difference after previous_rotation is stored).
- Threshold `still_qy` (max): operator_required (the clone states no at-rest bound on pose.pose.orientation; the operator supplies the largest change of this quaternion component over the confirmation window that still counts as still. Twist is not the check: the second publish in one step can carry a zero finite difference after previous_rotation is stored).
- Threshold `still_qz` (max): operator_required (the clone states no at-rest bound on pose.pose.orientation; the operator supplies the largest change of this quaternion component over the confirmation window that still counts as still. Twist is not the check: the second publish in one step can carry a zero finite difference after previous_rotation is stored).
- Threshold `still_qw` (max): operator_required (the clone states no at-rest bound on pose.pose.orientation; the operator supplies the largest change of this quaternion component over the confirmation window that still counts as still. Twist is not the check: the second publish in one step can carry a zero finite difference after previous_rotation is stored).
- Publisher history of `/Spot/odometry` (a new subscription's replay, discarded before any sample counts): volatile, cited `webots_spot/spot_driver.py:201`.
- Client execution bounds (no source: a wrong value can only withhold the confirmation): consecutive 3, min_span_ms 200, max_gap_ms 500, confirm_within_ms 3000.
- Safe state: Simulated only: /Spot/odometry shows the base still in x, y and orientation and inside the lying height band for three consecutive fresh samples after /Spot/float_mode false and /Spot/lie_down. Service answers are not the stop. Nothing is claimed past that window. Float mode, /cmd_vel, gait input and the stored previous_cmd_vel can move the base again. SpotArm is not stopped and Webots is not paused. Reset only re-checks that sensed state. (achieved by nothing declared).
