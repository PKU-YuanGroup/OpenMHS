## Safety

- E-stop: software, latching, native stop `/cmd_vel`, latency 4500 ms.
- Sensed-confirmation stop (simulated devices only; SAFE-049): the request steps `/cmd_vel` (topic), `/gait_type` (service) prove nothing by themselves. The e-stop is achieved only when every source (`/robot_odom` (nav_msgs/Odometry, stamp `header.stamp`), `/imu0` (sensor_msgs/Imu, stamp `header.stamp`)) delivers 3 fresh samples, on subscriptions opened after the request, that satisfy every term below within 1500 ms of the first transmission; otherwise it fails `MHS.SAFETY.SAFE_STATE_UNREACHED`, the latch is kept and the background retry sends the request again. A reset re-confirms without a request.
- Sensed state: zero velocity commanded and the standing gait requested; the base sensed still within the standing height band with a small angular rate in three consecutive fresh samples within the bound.
- Predicate: `max - min of odom.pose.pose.position.x over the window <= rest_x`.
- Predicate: `max - min of odom.pose.pose.position.y over the window <= rest_y`.
- Predicate: `odom.pose.pose.position.z >= standing_z.min and <= standing_z.max`.
- Predicate: `norm(imu.angular_velocity.x, imu.angular_velocity.y, imu.angular_velocity.z) <= rest_rate`.
- Threshold `rest_x` (max): operator_required (the clone states no at-rest bound; the operator supplies the largest change over the confirmation window that counts as standing still).
- Threshold `rest_y` (max): operator_required (the clone states no at-rest bound; the operator supplies the largest change over the confirmation window that counts as standing still).
- Threshold `standing_z.min` (min): operator_required (the clone states no standing height band (the stand trajectory z 0.21 and _body_height 0.25 are references, not bounds); the operator supplies it).
- Threshold `standing_z.max` (max): operator_required (the clone states no standing height band (the stand trajectory z 0.21 and _body_height 0.25 are references, not bounds); the operator supplies it).
- Threshold `rest_rate` (max): operator_required (the clone states no at-rest bound; the operator supplies the largest change over the confirmation window that counts as standing still).
- Client execution bounds (no source: a wrong value can only withhold the confirmation): consecutive 3, min_span_ms 200, max_gap_ms 500, confirm_within_ms 1500.
- Safe state: Simulated only: zero velocity commanded and the standing gait requested, and the base sensed standing still: the /robot_odom position within the operator's at-rest and standing-height bounds and the /imu0 angular rate below the operator's bound, in three consecutive fresh stamped samples within the confirmation bound. Another /cmd_vel publisher or the pybullet GUI mode buttons can move it again; nothing is claimed beyond the confirmation window. (achieved by nothing declared).
