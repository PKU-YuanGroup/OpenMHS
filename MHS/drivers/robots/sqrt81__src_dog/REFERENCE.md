## Actions

### `publish_joint_pd_frame`

`x-cap.sqrt81.joint_pd.v1` on `main`: invoke, risk R2, extension.

Publish one flat five-block std_msgs/Float64MultiArray motor frame on the Gazebo effort-controller command topic. The receipt confirms only that rosbridge accepted the publication, never that the controller received it, that a joint moved or that the robot stopped.

Inputs:

| Field | Type | Unit | Required | Limit | Description |
|---|---|---|---|---|---|
| `data` | array | 1 | yes | operator required (not set) | Flat Float64MultiArray data frame: indices 0-11 desired positions in rad, 12-23 kp in N.m/rad, 24-35 desired velocities in rad/s, 36-47 kd in N.m.s/rad and 48-59 feed-forward torques in N.m; the order is the twelve joints of controllers.yaml |

Outputs:

| Field | Type | Unit | Description |
|---|---|---|---|
| `published` | boolean |  | True when the driver handed the publication to rosbridge |
| `confirmed` | boolean |  | Always false: a rosbridge publication carries no execution or stopping confirmation |
