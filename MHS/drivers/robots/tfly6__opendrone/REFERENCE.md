## Actions

### `send_target_pose`

`x-cap.tfly6.target_pose.v1` on `main`: invoke, risk R2, extension.

Publish one opendrone/PlannerOutput to /planner/output. The base node latches the first point whose valid_mask has VALID_POSITION and republishes it as the position setpoint; the receipt confirms transmission only, not reception, arrival or motion.

Inputs:

| Field | Type | Unit | Required | Limit | Description |
|---|---|---|---|---|---|
| `points` | array |  | yes |  | PlannerOutputPoint array; the base node uses the first point with the VALID_POSITION bit and ignores the rest |
| `points[*].position` | object |  |  |  | position field of a PlannerOutputPoint, in metres |
| `points[*].position.x` | number | m |  |  | Position x in the message frame |
| `points[*].position.y` | number | m |  |  | Position y in the message frame |
| `points[*].position.z` | number | m |  |  | Position z in the message frame |
| `points[*].yaw` | number | rad |  |  | Yaw applied only when valid_mask also has VALID_YAW (32) |
| `points[*].valid_mask` | integer | 1 |  |  | Bitmask count: 1 = VALID_POSITION; 33 = VALID_POSITION \| VALID_YAW |

### `request_landing`

`x-cap.tfly6.land.v1` on `main`: invoke, risk R2, extension.

Fixed, input-free std_srvs/SetBool(true) request to the base node's /land service, an ordinary command: the callback stores the landing request and returns success before the node asks MAVROS for AUTO.LAND; the response proves neither the mode change nor touchdown, and the e-stop latch refuses it

## Safety

- E-stop: software, latching, native stop `/land`, latency 3500 ms.
- Sensed-confirmation stop (simulated devices only; SAFE-049): the request steps `/land` (service), `/mavros/cmd/arming` (service) prove nothing by themselves. The e-stop is achieved only when every source (`/mavros/state` (mavros_msgs/State, stamp `header.stamp`), `/mavros/local_position/pose` (geometry_msgs/PoseStamped, stamp `header.stamp`)) delivers 3 fresh samples, on subscriptions opened after the request, that satisfy every term below within 1500 ms of the first transmission; otherwise it fails `MHS.SAFETY.SAFE_STATE_UNREACHED`, the latch is kept and the background retry sends the request again. A reset re-confirms without a request.
- Sensed state: landing requested and locked in the base node; connected and disarmed on /mavros/state and the local pose low and at rest, sensed in three consecutive fresh samples within the bound.
- Predicate: `state.connected equals true`.
- Predicate: `state.armed equals false`.
- Predicate: `pose.pose.position.z <= landed_z.max`.
- Predicate: `max - min of pose.pose.position.x over the window <= rest_x`.
- Predicate: `max - min of pose.pose.position.y over the window <= rest_y`.
- Predicate: `max - min of pose.pose.position.z over the window <= rest_z`.
- Threshold `landed_z.max` (max): operator_required (the clone states no landed altitude band: the geo-fence lower bound z < -0.2 (base.cpp:345) is a fence, and touchdown is sensed by PX4 outside the clone; the operator supplies the band).
- Threshold `rest_x` (max): operator_required (the clone states no at-rest position bound; the operator supplies the largest position change over the confirmation window that counts as at rest).
- Threshold `rest_y` (max): operator_required (the clone states no at-rest position bound; the operator supplies the largest position change over the confirmation window that counts as at rest).
- Threshold `rest_z` (max): operator_required (the clone states no at-rest position bound; the operator supplies the largest position change over the confirmation window that counts as at rest).
- Client execution bounds (no source: a wrong value can only withhold the confirmation): consecutive 3, min_span_ms 200, max_gap_ms 500, confirm_within_ms 1500.
- Safe state: Simulated only: landing requested and locked in the base node, and the vehicle sensed landed, at rest and disarmed: /mavros/state connected and not armed, and /mavros/local_position/pose below the operator's landed band and still, in three consecutive fresh stamped samples within the confirmation bound. The /land response alone proves nothing; nothing is claimed beyond the confirmation window. (achieved by nothing declared).
- OpenMHS is not a safety certification and not a safety-rated channel; the physical e-stop stays authoritative.
