## Actions

### `publish_speed_command`

`x-cap.autorally.speed_command.v1` on `main`: invoke, risk R2, extension.

Publish one std_msgs/Float64 target velocity on the constantSpeedController/speedCommand topic. It does not publish /runstop and does not enable motion. The constant-speed controller consumes it; the receipt is transmission evidence only, not measured speed, arrival or stopping.

## Safety

- E-stop: software, latching, native stop `/constantSpeedController/speedCommand`, latency 4000 ms.
- Sensed-confirmation stop (simulated devices only; SAFE-049): the request steps `/constantSpeedController/speedCommand` (topic), `/runstop` (topic) prove nothing by themselves. The e-stop is achieved only when every source (`/wheelSpeeds` (autorally_msgs/wheelSpeeds, stamp `header.stamp`)) delivers 3 fresh samples, on subscriptions opened after the request, that satisfy every term below within 2000 ms of the first transmission; otherwise it fails `MHS.SAFETY.SAFE_STATE_UNREACHED`, the latch is kept and the background retry sends the request again. A reset re-confirms without a request.
- Sensed state: zero speedCommand and /runstop motionEnabled false from sender openmhs, then all four wheel speeds at or below the operator bound in three consecutive fresh samples within the bound.
- Predicate: `\|wheels.lfSpeed\| <= lf_speed`.
- Predicate: `\|wheels.rfSpeed\| <= rf_speed`.
- Predicate: `\|wheels.lbSpeed\| <= lb_speed`.
- Predicate: `\|wheels.rbSpeed\| <= rb_speed`.
- Threshold `lf_speed` (max): operator_required (the clone states no at-rest wheel-speed bound; the operator supplies the largest absolute wheel speed that counts as stopped over the confirmation window).
- Threshold `rf_speed` (max): operator_required (the clone states no at-rest wheel-speed bound; the operator supplies the largest absolute wheel speed that counts as stopped over the confirmation window).
- Threshold `lb_speed` (max): operator_required (the clone states no at-rest wheel-speed bound; the operator supplies the largest absolute wheel speed that counts as stopped over the confirmation window).
- Threshold `rb_speed` (max): operator_required (the clone states no at-rest wheel-speed bound; the operator supplies the largest absolute wheel speed that counts as stopped over the confirmation window).
- Client execution bounds (no source: a wrong value can only withhold the confirmation): consecutive 3, min_span_ms 200, max_gap_ms 500, confirm_within_ms 2000.
- Safe state: Simulated only: zero speedCommand and /runstop motionEnabled false from sender openmhs, then all four /wheelSpeeds magnitudes within the operator bound on three consecutive fresh samples. This package does not re-enable motion. The operator recovers outside MHS, and only after every other speedCommand publisher has stopped, because a lost or overwritten zero leaves the stored target in place. (achieved by nothing declared).
