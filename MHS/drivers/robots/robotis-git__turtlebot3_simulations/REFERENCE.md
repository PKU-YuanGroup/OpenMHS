## Actions

### `publish_velocity`

`x-cap.robotis-git.turtlebot3_sim_cmd_vel.v1` on `main`: invoke, risk R2, extension.

Publish one geometry_msgs/Twist to the upstream /cmd_vel subscription; the fake node consumes only linear.x and angular.z. The receipt confirms only that rosbridge accepted the publication, not motion, arrival or stopping. /cmd_vel is also a physical TurtleBot3 command topic, so this action is R2.
