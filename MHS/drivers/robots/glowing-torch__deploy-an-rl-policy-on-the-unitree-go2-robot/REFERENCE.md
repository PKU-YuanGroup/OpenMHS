## Actions

### `publish_joint_command`

`x-cap.glowing-torch.lowcmd.v1` on `main`: invoke, risk R2, extension.

Publish one unitree_go/msg/LowCmd on /mujoco/lowcmd with twelve MotorCmd entries carrying q, kp and kd; the receipt confirms only that rosbridge accepted the publication

Inputs:

| Field | Type | Unit | Required | Limit | Description |
|---|---|---|---|---|---|
| `motor_cmd` | array |  | yes |  | Twelve MotorCmd entries in the simulator's actuator order FR, FL, RR, RL |
| `motor_cmd[*].q` | number | rad |  | operator required (not set) | Target joint position |
| `motor_cmd[*].kp` | number | N.m/rad |  | operator required (not set) | Position gain applied by the node's PD law |
| `motor_cmd[*].kd` | number | N.m.s/rad |  | operator required (not set) | Velocity gain applied by the node's PD law |

| `confirmed` | boolean |  | Always false: a rosbridge publication carries no execution confirmation |
