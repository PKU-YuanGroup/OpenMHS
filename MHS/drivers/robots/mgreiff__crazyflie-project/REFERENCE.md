## Safety

- E-stop: software, latching, no native stop (software latch only).
- Safe state: No acknowledged stop exists: the e-stop fails MHS.SAFETY.SAFE_STATE_UNREACHED with the latch held, which only refuses this driver's commands; /crazyflie/emergency is answered by the external crazyflie_ros driver (the clone defines only the proxy), so nothing shows what the Crazyflie is left in, and an uploaded trajectory or the last command stays with the external driver and firmware. (achieved by nothing declared).
