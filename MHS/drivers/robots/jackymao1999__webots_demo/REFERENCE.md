## Safety

- E-stop: software, latching, no native stop (software latch only).
- Safe state: No acknowledged stop exists: an MHS e-stop only latches the driver, refusing further step requests, and reports MHS.SAFETY.SAFE_STATE_UNREACHED. It sends nothing to Webots; the realtime-mode simulation, the demo controller's own 32 ms time_step requests and the wheel velocities it last set from /cmd_vel continue. The 0 time_step request of the upstream Quit path is not bound: the clone does not show what it does. (achieved by nothing declared).
- OpenMHS is not a safety certification and not a safety-rated channel; the physical e-stop stays authoritative.
