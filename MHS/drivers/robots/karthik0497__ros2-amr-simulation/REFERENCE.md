## Actions

### `publish_cmd_vel`

`x-cap.karthik0497.cmd_vel.v1` on `main`: invoke, risk R2, extension.

Publish one geometry_msgs/Twist velocity setpoint to /cmd_vel for the gz-sim DiffDrive plugin. The receipt confirms only that rosbridge accepted the publication, not motion, arrival or stopping.

Inputs:

| Field | Type | Unit | Required | Limit | Description |
|---|---|---|---|---|---|
| `linear_velocity` | number | m/s | yes | operator required (not set) | Body-frame forward velocity written to twist.linear.x |
| `angular_velocity` | number | rad/s | yes | operator required (not set) | Body-frame yaw rate written to twist.angular.z |

Outputs:

| Field | Type | Unit | Description |
|---|---|---|---|
| `published` | boolean |  | True when the driver handed the Twist to rosbridge |
| `confirmed` | boolean |  | Always false: a rosbridge publication carries no execution or stop confirmation |

## Safety

- E-stop: software, latching, native stop `/cmd_vel`, latency 3500 ms.
- Sensed-confirmation stop (simulated devices only; SAFE-049): the request steps `/cmd_vel` (topic) prove nothing by themselves. The e-stop is achieved only when every source (`/odom` (nav_msgs/msg/Odometry, stamp `header.stamp`)) delivers 3 fresh samples, on subscriptions opened after the request, that satisfy every term below within 1500 ms of the first transmission; otherwise it fails `MHS.SAFETY.SAFE_STATE_UNREACHED`, the latch is kept and the background retry sends the request again. A reset re-confirms without a request.
- Sensed state: zero velocity commanded on /cmd_vel and the base sensed still on the /odom pose in three consecutive fresh samples within the bound.
- Predicate: `max - min of odom.pose.pose.position.x over the window <= rest_x`.
- Predicate: `max - min of odom.pose.pose.position.y over the window <= rest_y`.
- Predicate: `max - min of odom.pose.pose.orientation.z over the window <= rest_qz`.
- Predicate: `max - min of odom.pose.pose.orientation.w over the window <= rest_qw`.
- Threshold `rest_x` (max): operator_required (the clone states no at-rest bound for the odometry pose; the operator supplies the largest change over the confirmation window that counts as stopped).
- Threshold `rest_y` (max): operator_required (the clone states no at-rest bound for the odometry pose; the operator supplies the largest change over the confirmation window that counts as stopped).
- Threshold `rest_qz` (max): operator_required (the clone states no at-rest bound for the odometry pose; the operator supplies the largest change over the confirmation window that counts as stopped).
- Threshold `rest_qw` (max): operator_required (the clone states no at-rest bound for the odometry pose; the operator supplies the largest change over the confirmation window that counts as stopped).
- Publisher history of `/odom` (a new subscription's replay, discarded before any sample counts): operator_required (the /odom publisher is ros_gz_bridge's parameter_bridge, outside the clone; its bridge entry (src/robot_description/config/ros_gz_bridge.yaml:23-27) and launch parameters (src/robot_description/launch/gazebo.launch.py:144-153) set no QoS, so the bridge's default durability applies, which the clone does not state).

- Safe state: Simulated only: zero velocity commanded on /cmd_vel and the base sensed still on the bridged /odom pose (position and orientation within the operator's bounds) in three consecutive fresh stamped samples within the confirmation bound. The zero-Twist publication alone proves nothing; another /cmd_vel publisher can move the base again; nothing is claimed beyond the confirmation window. (achieved by nothing declared).
