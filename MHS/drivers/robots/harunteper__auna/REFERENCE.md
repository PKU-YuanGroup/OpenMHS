## Actions

### `select_velocity_source`

`x-cap.harunteper.velocity_source.v1` on `main`: invoke, risk R2, extension.

Select one configured multiplexer input source. Selecting OFF stops forwarding and makes the timer publish zero commands; selecting a motion source can immediately re-publish that source's cached last command.

Inputs:

| Field | Type | Unit | Required | Limit | Description |
|---|---|---|---|---|---|
| `source` | string |  | yes |  | Configured multiplexer source name; OFF selects the zero-command branch |

Outputs:

| Field | Type | Unit | Description |
|---|---|---|---|
| `success` | boolean |  | True when the multiplexer accepted the source name |
| `message` | string |  | Upstream response message naming the selected source |

### `publish_teleop_velocity`

`x-cap.harunteper.teleop_velocity.v1` on `main`: invoke, risk R2, extension.

Publish one speed and steering-angle command on the teleop multiplexer input. The multiplexer caches it and repeats it at its timer rate only while the teleop source is selected. The receipt confirms transmission to rosbridge, not motion, arrival or stopping.

Inputs:

| Field | Type | Unit | Required | Limit | Description |
|---|---|---|---|---|---|
| `speed` | number | m/s | yes | operator required (not set) | Forward speed written to twist.linear.x; negative values reverse |
| `steering_angle` | number | rad | yes | operator required (not set) | Steering angle written to twist.angular.z and copied to drive.steering_angle |

Outputs:

| Field | Type | Unit | Description |
|---|---|---|---|
| `published` | boolean |  | True when rosbridge accepted the topic publication |
| `confirmed` | boolean |  | Always false: a publication carries no execution confirmation |

### `stop_velocity_source`

`x-cap.harunteper.stop.v1` on `main`: invoke, risk R2, extension.

Set the multiplexer velocity source to OFF, making its timer publish zero speed and steering commands. Input-free, acknowledged service call; no input is accepted during the latch.

Inputs:

None.

Outputs:

| Field | Type | Unit | Description |
|---|---|---|---|
| `source_off` | boolean |  | True when the multiplexer acknowledged the OFF source |

## Safety

- E-stop: software, latching, native stop `/robot1/toggle_cmd_vel_source`.
- Safe state: The multiplexer velocity source is set to OFF and its timer publishes zero speed and steering commands on cmd_vel_twist; the service acknowledgement is not sensed vehicle quiescence, the cached source message is retained, and re-selecting a source re-publishes the cached command. Any client of toggle_cmd_vel_source, such as the control panel, can re-select a source while MHS is latched. (achieved by `x-cap.harunteper.stop.v1`).
- Operator-required limits not yet set: `publish_teleop_velocity.speed`, `publish_teleop_velocity.steering_angle`. Hardware use is refused (MHS.SAFETY.LIMITS_UNSET) until site-limits.json supplies them.
- OpenMHS is not a safety certification and not a safety-rated channel; the physical e-stop stays authoritative.
