## Actions

### `publish_cmd_vel`

`x-cap.taucrates.cmd_vel.v1` on `main`: invoke, risk R2, extension.

Publish one geometry_msgs/Twist velocity setpoint to the CHAMP cmd_vel endpoint. The receipt confirms only that rosbridge accepted the publication, not motion, arrival or stopping.

Inputs:

| Field | Type | Unit | Required | Limit | Description |
|---|---|---|---|---|---|
| `linear_x` | number | m/s | yes | operator required (not set) | Body-frame forward velocity written to twist.linear.x |
| `linear_y` | number | m/s | yes | operator required (not set) | Body-frame lateral velocity written to twist.linear.y |
| `angular_z` | number | rad/s | yes | operator required (not set) | Body-frame yaw rate written to twist.angular.z |

Outputs:

| Field | Type | Unit | Description |
|---|---|---|---|
| `published` | boolean |  | True when the driver handed the Twist to rosbridge |
