## Safety

- E-stop: software, latching, native stop `stop`.
- Safe state: the car is stopped: speed and steering are set to 0 and the simulator's stop command is sent (Car.stop), which closes the client connection (achieved by nothing declared).
- Operator-required limits not yet set: `sensor_angle`. Hardware use is refused (MHS.SAFETY.LIMITS_UNSET) until site-limits.json supplies them.
- OpenMHS is not a safety certification and not a safety-rated channel; the physical e-stop stays authoritative.
