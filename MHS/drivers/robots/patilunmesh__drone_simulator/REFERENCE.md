## Actions

### `reset_sim`

`x-cap.patilunmesh.reset.v1` on `main`: invoke, risk R1, extension.

Reset the CBF demo simulation through the ResetSim service: the node returns to its initial position, replans the trajectory and recreates its 10 Hz timer. The done flag acknowledges the callback, not a stopped state.

Inputs:

| Field | Type | Unit | Required | Limit | Description |

| `cbf_param` | number | 1 | yes | operator required (not set) | CBF cautiousness parameter passed to ResetSim; the clone states no numeric range |

Outputs:

| Field | Type | Unit | Description |
|---|---|---|---|
| `done` | boolean |  | True when the ResetSim callback returned done=true |
