## Actions

### `publish_attitude_thrust`

`x-cap.gsilano.attitude_thrust.v1` on `main`: invoke, risk R2, extension.

Publish a roll/pitch/yaw-rate/thrust setpoint on the Crazyflie command topic; publication is fire-and-forget and does not confirm flight or stopping

Inputs:

| Field | Type | Unit | Required | Limit | Description |
|---|---|---|---|---|---|
| `roll` | number | rad | yes | operator required (not set) | Desired roll attitude in radians |
| `pitch` | number | rad | yes | operator required (not set) | Desired pitch attitude in radians |
| `yaw_rate` | number | rad/s | yes | operator required (not set) | Desired yaw rate in radians per second |
| `thrust` | number | 1 | yes | operator required (not set) | Thrust command on the upstream joystick's configurable PWM-like scale; the controller saturates its rotor output |

Outputs:

| Field | Type | Unit | Description |
|---|---|---|---|
| `published` | boolean |  | True once rosbridge accepted the publication |
| `confirmed` | boolean |  | Always false: a topic publication has no controller or simulator acknowledgement |
| `sent_roll` | number | rad | The roll handed to rosbridge (the transmitted request, not a measured attitude) |
| `sent_pitch` | number | rad | The pitch handed to rosbridge (the transmitted request, not a measured attitude) |
| `sent_yaw_rate` | number | rad/s | The yaw rate handed to rosbridge (the transmitted request) |
| `sent_thrust` | number | 1 | The thrust handed to rosbridge (the transmitted request) |

## Safety

- E-stop: software, latching, native stop `/gazebo/pause_physics`.
- Safe state: The Gazebo world is paused and get_physics_properties read pause true back: no world update runs, so the motor models apply no rotor force and odometry is silent; it is the paused flag, not a measured standstill. No unpause is offered: an operator re-commands or lands the vehicle and unpauses outside MHS (Gazebo GUI or rosservice call gazebo/unpause_physics). (achieved by nothing declared).
- Operator-required limits not yet set: `publish_attitude_thrust.pitch`, `publish_attitude_thrust.roll`, `publish_attitude_thrust.thrust`, `publish_attitude_thrust.yaw_rate`. Hardware use is refused (MHS.SAFETY.LIMITS_UNSET) until site-limits.json supplies them.
- OpenMHS is not a safety certification and not a safety-rated channel; the physical e-stop stays authoritative.
