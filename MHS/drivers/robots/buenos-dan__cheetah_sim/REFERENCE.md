## Actions

### `move_joint`

`x-cap.buenos-dan.leg_position.v1` on `main`: invoke, risk R2, extension, cancellable.

Publish one joint-angle command to a leg's position controller. The angle is the value before the per-leg JOINT_OFFSET; the upstream method adds that fixed offset and publishes a std_msgs/Float64. The receipt confirms that the message was handed to the publisher, not that the joint moved or reached the target.

Inputs:

| Field | Type | Unit | Required | Limit | Description |
|---|---|---|---|---|---|
| `leg` | string |  | yes |  | Leg whose position controller receives the command |
| `joint` | string |  | yes |  | Joint within the leg, mapped through LegController.joint_name |
| `angle_rad` | number | rad | yes | operator required (not set) | Joint angle before the fixed per-leg JOINT_OFFSET |

Outputs:

| Field | Type | Unit | Description |

| `joint` | string |  | Joint that received the command |
| `joint_index` | integer | 1 | Zero-based index in LegController.joint_name |
| `angle_rad` | number | rad | Joint angle before the fixed offset |
| `published` | boolean |  | True when the publisher call was made |
| `confirmed` | boolean |  | Always false: the upstream publisher has no execution or arrival acknowledgement |

### `stand`

`x-cap.buenos-dan.stand.v1` on `main`: invoke, risk R2, extension.

Command the four legs to the upstream fixed stand end-effector pose. This is an active posture command, not a stop or a measured stand: the position controllers provide no quiescence acknowledgement, so it is not a safe-state action and is refused while the e-stop is latched.

Inputs:

None.

Outputs:

| Field | Type | Unit | Description |
|---|---|---|---|
| `legs` | array |  | Legs commanded to the stand pose |
| `commanded` | boolean |  | True when the stand publication calls were made |
| `confirmed` | boolean |  | Always false: the upstream publisher has no posture or quiescence acknowledgement |
