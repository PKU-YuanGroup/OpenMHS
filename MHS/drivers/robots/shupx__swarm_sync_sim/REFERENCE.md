## Safety

- E-stop: software, latching, native stop `/sss_clock_control`.
- Safe state: The acknowledged /sss_clock_control request sets is_paused_, so the speed regulator (time client 0) stops posting clock requests; as try_update_clock publishes /clock only when every client, client 0 included, has a new request, simulated time advances at most the pending 0.01 s regulator step and then holds, freezing nodes timed on simulated time, until any ROS client, the shipped clock UI Start button or speed dial included, sends proceed=true. (achieved by `x-cap.shupx.pause.v1`).
- Operator-required limits not yet set: `resume.max_sim_speed`. Hardware use is refused (MHS.SAFETY.LIMITS_UNSET) until site-limits.json supplies them.
- OpenMHS is not a safety certification and not a safety-rated channel; the physical e-stop stays authoritative.
