## Safety

- E-stop: software, latching, no native stop (software latch only).
- Safe state: No actuation is bound: this package only subscribes to the simulator's declared telemetry topics and commands no motion, so an MHS e-stop is the runtime software latch and no native or physical stop is claimed. (achieved by nothing declared).
- OpenMHS is not a safety certification and not a safety-rated channel; the physical e-stop stays authoritative.
