# Finite MCP controlled-client helper

OpenMHS is independent and is not affiliated with, endorsed by, or a reimplementation of Anthropic's MHS research preview.

The SDK gains a config-only `McpClientDriver`, finite compiler, retained-request
bridge, source/wire checker and complete synthetic Rigol fixture. It reuses stock
loader admission, resolved risks, limits, permits, receipts and artifact grants.
All thirteen default tools remain available, including effectful configuration,
six acquisition actions, full returned waveform arrays and PNG bytes. Explicit
cursor bindings preserve seconds/volts and the source's omitted-type branch.

Controlled tests cover full stock loader/server/MCP data paths, strict input and
output budgets, discovery and policy integrity, scoped replay/retrieval/expiry,
unknown effects, late responses, fresh protective proof/reset and close cleanup.
The correctly packaged fixture passes unmodified fake G1–G9 with the explicit
synthetic and unresolved-native warning boundaries. Source proof is static and
the fixture is model-authored; no human review or device execution is claimed.

Every native entrypoint refuses before import/spawn/connect. Real MCP transport,
device-state retirement, deployment and license constraints remain open, and no
registry/card/package is enabled. The author's SDK15 baseline also requires the
separately accepted core public-response deep-copy fix for receipt mutation
isolation; composition and the unchanged ownership witness remain explicit
integration work. The helper itself makes no server or artifact-schema change.
