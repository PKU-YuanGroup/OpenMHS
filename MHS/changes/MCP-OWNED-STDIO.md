# Owned controlled MCP stdio and terminal proof revocation

OpenMHS is independent and is not affiliated with, endorsed by, or a reimplementation of Anthropic's MHS research preview.

A concrete controlled POSIX peer can now exercise the complete Rigol-shaped
fixture through real stdio pipes, ordinary package loading, server receipts and
MCP artifact resources. The fixed SDK child has finite framing, byte/identity
budgets, exact request correlation, separate writer/reader/stderr ownership and
bounded process-group retirement stages. No caller chooses a command, endpoint
or native server, and every native Driver/factory entrypoint continues to refuse.

Terminal owned-peer health now revokes old controlled safety proof, including
idle EOF and non-effectful result errors. Stop and reset commit only with the
current live owner epoch. Local timeout, cancellation, semantic rejection and
close retain request ownership through software retirement; uncertain cleanup
remains explicitly owned. Neither cancellation nor child exit proves physical
stopping. A caller can defer host interruption while cleanup progresses, but
abrupt host death is unsupported by the in-process supervisor.

Controlled tests retain all thirteen tools and sixteen bindings, optional/null
configuration and cursor variants, complete returned screen/memory arrays and
exact PNG pixels, units, selectors, limits/permits, session-scoped grants, replay,
expiry and late-output refusal. The original full fake G1-G9 fixture is unchanged;
synthetic-source and unresolved-native warnings retain their explicit meaning.
New G3 controls cover computed mutation of the transport and policy functions.

Pinned native discovery/string-result incompatibilities, synchronous upstream
server behavior, SCPI ownership/retirement, device bounds and license/deployment
conditions remain separate open work. No native package, human signature,
hardware execution, registry activation or publication is claimed.
